# Credits

This is a fan-made reconstruction of Rocket Crowbar 1.9. It is not affiliated with or endorsed by its
author. Everything below comes from the files RC 1.9 itself ships (`rockcrowbarv19.zip`,
`RockCrowbar/`); each entry names its source. Where a file names nobody, the entry says so instead of
guessing.

## Rocket Crowbar

- **Author:** Laser (laser@planethalflife.com): "Rocket Crowbar MOD (Ver. 19), By Laser" (Readme.txt).
- **Copyright:** "This mod is copyrighted by Derek Hageman, 1999-2001." (Readme.txt)
- **Thanks, as Readme.txt lists them:** Valve ("Duh, Great Game"); Katsuro, for the "RocketCrowbar(tm)"
  model; Robert "aXon" Stephens, for the HUD sprites; cheesemonster, for a third-party bot; Dayzed and
  Kersplat, from Laser's beta server; and "anyone else who came to my beta server and behaved".
- **The flag model** is Laser's own ("I know the flag model is bad, I am not a great modeler",
  Readme.txt).
- **The other models, sounds and sprites** (`panther.mdl`, `db.mdl`, the `rcbaddtions/` sounds, the
  flares) ship without a credit; they are presumably Laser's.

Rocket Crowbar 2's shipped `credits.txt` (2004) gives a different account of RC's code: "NinjaX9 -
original programmer for Rocket Crowbar. Laser - 2nd project manager, developed most of the RC2 code."
RC 1.9's own readme names only Laser.
