# reference/ - original Rocket Crowbar 1.9 artifacts

Source-of-truth binaries from the original mod, kept for reconstructing the game
library as C++ on this SDK. Reference only, not linked into any build.

| File | What it is |
|---|---|
| `rc_i386.so` | Linux 32-bit server library, egcs 1.1.2 / gcc 2.95.4, **not stripped**. 5,498 functions with names and addresses, and the names of the 130 source files it was built from. |
| `rc.dll` | Windows 32-bit server library, MSVC, built 2001-09-13 22:02 UTC. No PDB (debug file); 304 mangled exports (save/restore callbacks, fully typed once demangled) and 357 unmangled (entity classnames, engine API). |
| `sourcefiles.txt` | The 130 source file names from the .so's symbol table. 100 are stock SDK files; the other 30 are RC's own (curses, deathballs, flag, the drive* monsters, voting, pregame, rc.ini prefs). |

Generated by `./dump-signatures.sh` (needs llvm-undname and binutils):
`exports-rc.raw`, `signatures-rc.txt`, `entities-rc.txt`, `symbols-gcc2.txt`,
`signatures-gcc2.txt` (gcc 2.x names demangled by `../scripts/gnv2demangle.py`,
copied from mod-ts; 4,481 of 5,498 parse), `classes.txt`.

## Provenance

Both libraries are byte-identical in the v19 release (`rockcrowbarv19.zip`,
2,754,360 bytes, `RockCrowbar/dlls/`) and in a server install from 2002.

```
ccae2ebf8182be7c94cc2f2fcc85c9e4  rc.dll
66b615302fff272265fc699dd72bae48  rc_i386.so
```

That install also has an older `rc.dll` at its top level (built 2001-04-11, md5
10817d8e9e9e008a84767773e5f34030), from before v19. The Wayback Machine has the
v19 Windows installer (`rocketcrowbar.com/downloads/files/rockcrowbarv19.exe`,
archived 2003-12-21); 7z can't open its format, so it hasn't been compared.

## Related
