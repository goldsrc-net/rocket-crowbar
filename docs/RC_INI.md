# rc.ini keys

Generated by `scripts/prefs_keys.py`; don't edit by hand. Every key the rebuild reads from
`rc.ini` (the file `sv_prefsfile` names, in the game directory), with the default the code
uses when the key is missing. A missing key is added to the in-memory table with that default,
and `saveprefs` writes it out (docs/SERVER.md).

Curse keys are per curse: `<curse>` is one of `Reversal`, `Slowness`, `Slowrefire`, `DmgMirror`, `DmgScale`, `Drunkness`, `ProMagnet`, `SlowDeath`.
The `shipped` column is RC 1.9's own `rc.ini`; a blank one means the release doesn't set it.
